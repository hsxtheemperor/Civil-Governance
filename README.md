# CJP — Code of Conduct Repository

## What is this?

This repository holds the official **Code of Conduct (CoC)** for the CJP community — a shared set of values and guidelines for how members engage with each other, their peers, and their country.

The CoC is a  **living document** . It grows and improves as the community grows.

---

## Why does this exist?

A community without shared standards is just a crowd.

This CoC gives every CJP member a clear reference point to measure their own conduct — and a foundation to build a better civic culture, starting with themselves.

The goal is not to police people. It is to give everyone a common language for what good citizenship and good community behaviour looks like.

---

## What's in this repo?

| File                       | What it is                                              |
| -------------------------- | ------------------------------------------------------- |
| `CODE-OF-CONDUCT.md`     | The main Code of Conduct — the values and guidelines   |
| `CONTRIBUTION.md`        | How to suggest changes or additions to the CoC          |
| `TERMS-OF-SUGGESTION.md` | What kinds of suggestions are welcome (and what aren't) |

---

## How do I suggest a change?

1. Read `CODE-OF-CONDUCT.md` fully first
2. Read `TERMS-OF-SUGGESTION.md` to check if your idea fits
3. Follow the steps in `CONTRIBUTION.md` to open a Pull Request

All suggestions, discussions, approvals, and rejections are **public and recorded** — nothing happens behind closed doors.

---

## Who maintains this?

This repository is maintained by CJP community contributors.
Changes are reviewed openly and can only be rejected with a clear, stated reason.
